❓ あそびかたガイド
① ゲームの目的
  • 右から左へ進んでくる敵を倒して、拠点(左端)を守るゲームです。
  • 敵が拠点に到達するとライフが1減ります。ライフ(最初は20)が0になるとゲームオーバー。
  • 「▶ ウェーブ開始」を押すと敵が出現。ウェーブが進むほど敵のHPが上がり、10ウェーブごとにボスが出ます。
  • 上の「平均敵HP」「最大敵HP」は、そのウェーブの敵のHPです(進行中はそのウェーブ、待機中は次のウェーブ。ボスの回は最大HPがボスのHP)。「最大ダメージ」は、これまでに与えた1回のダメージの最大値です。DPSは、敵のHPを超えた分のダメージも数えます。
  • チュートリアル中は、説明されているボタンだけが押せます(ほかの場所を押すと、案内が出ます)。
  • 画面のボタン「🏠オーブショップ」でオーブの購入と装着、「🛠強化一覧」でオーブの合成(コード入力もここ)ができます。下にスクロールする必要はありません。
  • 敵を倒すとゴールドがもらえます(ボスは5倍)。ゴールドでタワーとオーブを買って強くなりましょう。

基本の攻撃力と速度です。オーブや進化値でさらに強化されます。
  • 画面右下の3×3のマスをタップして選び、下に出る「建てるタワー」から種類を選ぶと建設できます。
  • ノーマル(30G):バランス型。
  • スピード(50G):攻撃は弱いが超高速。
  • 連結(70G):場にあるほかの連結・鉄塔(連結の効果を持つ)1つごとに、連結と鉄塔の攻撃+25%・速度+15%(インフレ系モードでは+100%ずつ)。連結を何個つなげても、全員が同じ量だけ強くなります。さらに、隣り合う連結以外のタワー1つごとに同じだけ上がります。
  • パワー(60G):遅いが一撃が重い。
  • チャージ(50G):自動では攻撃しません。タワーのマスをタップすると、いちばん前の敵を攻撃します。最後に攻撃してからのチャージ時間が0.1秒増えるごとに、ダメージが+1%(1秒で+10%)上がります。チャージ時間はタワーに表示され、攻撃するとリセットされます(円柱のゲージは+100%(10秒)たまるごとに満タンになり、色が変わって次の周が始まります。黄→橙→赤→紫→青→水色→緑の順で、その後は黄に戻ります。ダメージの上昇は止まりません)。
  • 背水の陣(200G):ノーマル以外のモードで登場。敵が拠点に近づくほどダメージが上がり、拠点ぎりぎりで最大×999。タワーを選んで💎を40個使うと、攻撃速度も同じように上がります(最大×9999)。
  • タワーの円柱は種類ごとに見た目が違います:ノーマル=白と灰色、スピード=青(スピード線)、連結=黄色(シアンの鎖)、パワー=赤(帯)、鉄塔=鋼色(シアンの鎖)、チャージ=色が変わるゲージ。
  • 鉄塔*(最凶モード限定):ノーマル・スピード・連結・パワーを場に1つずつ建て、進化オーブを1つ持っていると、「合成」欄に鉄塔のボタンが出ます。押すと4タワーが1つの鉄塔になり(いちばん小さい番号のマスに建ちます)、4種すべての効果を持ちます。初期ステータスは攻撃50・毎秒5発。
  • 鉄塔・段階タワー(デスモード限定):デスモードでは、鉄塔を建てるメニューから最初から建てられます(210G)。鉄塔を3つと進化オーブ1つを持っていると、「合成」欄に「段階タワー」のボタンが出ます(いちばん小さい番号のマスに建ちます)。段階タワーは鉄塔と同じ4種の効果を持ち、初期は攻撃150・毎秒5発です。
  • 段階タワーのレベル:マスを選んで、ゴールドで「+1Lv」「+10Lv」。レベルアップに必要なゴールドは、いまのレベル×100です。ダメージ上昇は、Lv2〜5が1レベルごとに+50%、Lv6〜15が+80%、Lv16〜30が+120%、Lv31〜は+200%から始まって1レベルごとに+10%ずつ増えます(Lv32は+210%)。Lv16から範囲ダメージが付き、攻撃するたびに範囲が5%ずつ広がります。
  • タワーを選ぶと「売却」が出ます(購入額の70%が戻ります)。
  • オーブの効果は全タワーに共通でかかります。
③ オーブの使い方
  • 下の「オーブショップ」でゴールドを使って買います(スピード30G / パワー40G / 進化50G / 確率特化200G)。×1・×10・×100で購入数を切り替えられます。
  • 「所持オーブ」のオーブをタップすると、左のオーブ枠(最大4個)に装着されます。枠のオーブをタップすると外せます。
  • スピード:速度+10% / パワー:攻撃+20%
  • 少強化:速度・攻撃+20% / 強化:+80% / 超強化:+1000%
  • 確率特化:7%の確率でダメージ5倍
  • 即死:5%でダメージ100倍、3%で即死
  • 確率強化:攻撃するとき10%の確率で、そのタワーが100秒間、攻撃力と攻撃速度が4倍になります。
  • 確率割合:攻撃するとき15%の確率で、敵の現在HPの40%を削る攻撃になります。
  • 万能:攻撃力と攻撃速度が常に99倍。さらに攻撃するとき、20%で敵の現在HPの80%を削る・20%で即死・50%で攻撃力と次の攻撃までの速さが5000倍。5回攻撃するごとに、ダメージが+10%ずつ上がっていきます。
  • 進化オーブ単体には攻撃力アップの効果はなく、進化値を貯めるために使います。
④ オーブの進化(合成)方法
  • 合成は、画面の「合成」欄のボタンで行います。素材が揃ったオーブのボタンだけが表示されます。
  • 素材に使えるのは「所持オーブ」にあるものだけです(枠に入れているオーブは数えません)。
  • 少強化:進化+パワー+スピード / 強化:少強化×3
  • 強進化:強化×3 / 極進化:少強化+強化
  • 超進化:進化×2+少強化 / 深淵:進化+少強化+強化+確率特化
  • 超強化:強進化+極進化+超進化+深淵
  • 確率強化:確率特化+進化 / 確率割合:確率特化×2
  • 上限解放:超強化×3(進化値150以上)
  • 即死:確率強化+上限解放+確率割合+超強化(進化値200以上)
  • 万能:即死×2+上限解放
  • 強進化・極進化・超進化・上限解放には単体の効果はなく、超強化や即死の素材です。深淵は素材のほか、装着すると倒した敵を深淵に引きずり込みます(下の効果一覧を参照)。
  • 進化値が足りない間は、上限解放と即死のボタンは出ません。
  • 一度作ったオーブは買える:合成で一度作ったオーブは、次からオーブショップにゴールドで並びます(合成に使う材料の値段の合計の1.1倍)。この記録はセーブされ、次のプレイにも残ります。
  • オーブ強化:「🛠強化一覧(合成)」で、強化したいオーブ1個と進化オーブ(Lv+1個)を合成すると、そのオーブの効果が+50%ずつ強くなります(最大Lv10)。強化できるのは、スピード・パワー・少強化・強化・超強化・確率特化・確率強化・確率割合・深淵・即死・万能です(深淵は復活の攻撃力バフの倍率と時間も伸びます)。
⑤ 進化値の貯め方
強化 合成解放 ダイヤ
  • オーブ枠4つすべてに「進化」オーブを入れると「★ 4枠進化」ボタンが出ます。押すと進化値+5(枠のオーブは消費)。
  • 進化値は上のステータス欄に表示され、貯まるほど永続で強くなります。
  • 10:範囲攻撃 / 25:オーブ効果+5%
  • 50:強打発生(10%で5倍) / 100:強打率50%
  • 1000:攻撃力×11 / 5000:強打が80倍
  • 9999:攻撃するたび攻撃力+1% / 10000以降:進化値+1ごとにダメージ+10%
  • 画面上部の「10:範囲攻撃 / 25:…」は達成済みだと緑になります。
⑥ ダイヤとダイヤタワー
  • 即死オーブを装着し、進化値が500以上だと、敵を倒すたびに💎を1個獲得。
  • 💎を10個集めたら、オーブ枠の下のダイヤマークをタップするとダイヤタワーが建ちます。
  • ノーマルモードでは、最もHPが高い敵の現在HPの10%を削り続けます。
  • 💎はタイトル画面の「タワー強化」にもためられます。💎20個で、全タワーの初期ステータス(攻撃・速度)が+5%。強化するたびに必要な💎が1.5倍(小数点以下は切り捨て)になります。
⑦ モードとセーブ
  • ノーマル:基本ルール。
  • デス:インフレーションと同じルール。最初の敵HPが50万で、毎ウェーブ3倍。ウェーブ後半の敵ほど硬くなり、最後の敵は1.5倍のHPです。最初の所持ゴールドは250です。鉄塔を最初から建てられ、鉄塔3つ+進化オーブ1つで段階タワーを作れます。
  • 最凶:インフレーションと同じルールで、敵HPの上昇がさらに激しいモード。体力40から毎ウェーブ2.5倍ずつ上がり(40→100→250…)、同じウェーブの中でも後に出る敵ほど硬くなります。
  • インフレーション:敵HPが毎ウェーブ1.5倍ずつ上昇。ノーマルはレーザー、連結は隣接タワーの数だけ強化、パワーは最初から範囲攻撃、ダイヤタワーは通路で敵を即死させるなど、タワーの性質が変わります。
  • 進行状況は自動保存されます。「中断」でタイトルに戻り、「続きから」で再開できます。
  • テスト欄(進化値を直接設定できるボタン)は、画面下の「コード」欄に隠しコードを入れると使えるようになります。

⑨ サプライズボックス
  • 5ウェーブごと(5・10・15…)に、ウェーブの途中で、敵通路に🎁のサプライズボックスが1個流れてきます。
  • ボックスのHPは、そのウェーブの通常の敵の10%です。拠点に着いても、ライフは減りません。
  • 倒すと、次の7つの効果のうち、どれか1つがランダムでつきます。
  • 所持ゴールドが2倍
  • 所持ゴールドが1/3(小数点以下は切り捨て)
  • 60秒間、タワーのステータス(攻撃・速度)が8倍
  • 2ウェーブの間、敵のHPが5倍
  • 💎を3個すぐにもらえる
  • 30秒間、敵のスピードが50%速くなる
  • 進化値+20(すぐに)
  • 効果の残り時間は、ステータス欄の下に表示されます。
